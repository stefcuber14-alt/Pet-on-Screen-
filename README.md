# Питомец на экране 🐾

Нативное Android-приложение с плавающим питомцем и загрузкой собственных GIF-анимаций.

## Сборка APK через GitHub Actions
1. Создай пустой GitHub-репозиторий.
2. Распакуй ZIP и загрузи **всё содержимое** в корень репозитория (включая скрытую папку `.github`).
3. Открой вкладку **Actions** и дождись завершения `Build Android APK`.
4. Открой успешный запуск и скачай artifact `PetOnScreen-debug-apk`.
5. Внутри будет `app-debug.apk`.

## Возможности
- имя, характер и цвет запасного персонажа;
- импорт GIF-файлов из файлов телефона;
- отдельные GIF для обычного состояния, ходьбы, сна и реакции на касание;
- плавающее окно поверх других приложений;
- перетаскивание питомца пальцем;
- GIF ходьбы во время перетаскивания и GIF реакции при касании;
- постоянное уведомление Android, пока питомец активен.

## Использование GIF
В приложении нажми нужную кнопку GIF и выбери файл с типом `image/gif`. GIF копируется в память приложения, поэтому исходный файл можно не хранить в отдельной папке. Для ходьбы используется назначенная GIF при перетаскивании, для реакции — при касании. GIF сна и обычного состояния можно загрузить отдельно; автоматическое расписание сна пока не реализовано, а обычная GIF используется в спокойном состоянии.

## Важно
При первом запуске Android попросит разрешение «Поверх других приложений». Его нужно включить вручную. Пока питомец отображается поверх других приложений, Android показывает постоянное уведомление. Некоторые версии Android и оболочки могут ограничивать фоновые службы и автозапуск.

Это исходный проект, а не готовый APK. Сборку необходимо проверить через GitHub Actions.
